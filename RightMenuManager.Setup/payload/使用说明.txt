================================================================
 Windows 11 右键菜单管理器 —— 使用说明
================================================================

【怎么打开】
   双击本文件夹里的「右键菜单管理器.exe」。就这样，不用安装。

   第一次打开会自动扫描你电脑上所有的右键菜单项，大约一秒钟后
   列表就出来了。


================================================================
 它能帮你做什么
================================================================

一、看清楚是谁往你的右键菜单里塞了东西
   列表里每一行都是右键菜单里的一项。最上面有两个下拉，是最常用的筛法：

   ┌─「全部来源」下拉 ──────────────────────────────
   │  全部来源        什么都不筛
   │  Windows 自带    Windows 自己的功能
   │  第三方软件      各种软件装进来的
   │                  （想看「谁动了我的菜单」就选这个）
   └───────────────────────────────────────────────

   ┌─「全部位置」下拉 ──────────────────────────────
   │  全部位置           什么都不筛
   │  右键文件时         右击一个文件会看到的
   │  右键文件夹时       右击一个文件夹会看到的
   │  右键文件夹空白处   打开文件夹、在空白处点右键会看到的
   │  右键桌面空白处     在桌面空白处点右键会看到的
   │  右键快捷方式时     右击一个快捷方式（.lnk）会看到的
   │  右键程序时         右击一个 exe 会看到的
   │  Win11 现代菜单     Windows 11 精简菜单里的（QQ、Bandizip 这些用新方式注册的）
   │  右键文件和文件夹时 上面两种都适用
   │  右键驱动器时       右击 C 盘、D 盘这类
   │  「发送到」菜单     「发送到」子菜单里的
   │  仅某种文件类型     只对 .zip、.jpg 这类特定文件出现
   │  其他位置           没归进上面任何一类的
   └───────────────────────────────────────────────

   两个下拉可以叠加用。比如想清理「右击文件夹时冒出来的第三方东西」：
   来源选「第三方软件」，位置选「右键文件夹时」，剩下的就是目标。

   列表里的列名和这两个下拉是同一套说法（「在哪儿右键」「哪个程序」「谁装的」），
   点列还能排序。想找特定的东西，用最左边的搜索框，名称和程序路径都能搜。

   「哪个程序」这一列专门用来跟真实菜单对号：你在菜单里看到
   「用 HiBit Uninstaller 卸载」，按这一列找到 HiBitUninstaller.exe，
   就是那一条。

   名称后面带「（共 N 处）」的，说明同一个程序在 N 个地方各注册了一份
   （常见于压缩软件，它认识的每种扩展名下都挂一份）。它是一条代表，
   点「停用」或「删除」会把 N 处一起处理，不会漏掉。

   「含文件类型专属项」默认不勾。勾上会多出几百条「只对 .zip 文件
   右键才出现」这种，几乎全是系统自带的，一般不用管。

二、找出软件卸载后留下的垃圾
   勾上「只看失效残留」。剩下的就是「指向的程序已经不在硬盘上了」的项，
   多半是某个软件卸载没卸干净留下的空壳，删掉不会有任何影响。

   程序不会瞎猜：只有它确实拿到了完整路径、而且那个文件真的不存在，
   才会标成失效。如果命令里只写了个程序名（比如 powershell.exe），
   它会去系统目录和 PATH 里找一遍，找不到也不下结论。

三、让它消失（两种做法，都留后路）
   · 停用 —— 什么都不删，只让它在菜单里不出现。想反悔就点「恢复启用」。
             拿不准的先用这个试。

   · 删除 —— 先把这一项完整备份成一个文件，再删掉。
             备份默认放在「我的文档\右键菜单备份\」，文件名带时间戳。
             删错了，到「备份与还原」页面点「还原选中」就回来了。

             想换个地方存（比如 D 盘、或者网盘同步目录），点「备份与还原」
             页面上的「更改位置」，挑一个文件夹就行，选择会记住。
             当前存在哪儿，页面上那行字写着。

   这两种操作都能一次处理多项，两种选法随便挑：

   · 按住 Ctrl 再点，可以挑着选好几项；按住 Shift 再点，可以连选一整段
   · 或者点上面的「批量选择」—— 每一行左边会出现勾选框，点勾就行，
     完全不用碰键盘。旁边的「全选」能一次勾上当前列表里的全部项，
     再点一次「退出批量选择」就关掉。

   选中（或勾选）多项时，右边会显示「已选中 N 项」，按钮也跟着变成
   「停用这 N 项」「删除这 N 项（先备份）」，点一下全部处理。

   注意：操作完列表会停在原地，不会把你弹回最上面，可以接着往下清。

四、把右键菜单变回 Windows 10 那样
   点右上角「切换完整右键菜单」。

   Windows 11 默认把菜单折叠成一小撮，要点「显示更多选项」才看得全。
   切换之后所有项目直接展开，跟 Win10 一样。
   想变回去，再点一次（按钮会变成「返回 Win11 默认菜单」）。


================================================================
 改完没反应？
================================================================
   右键菜单是「资源管理器」（管桌面和任务栏的那个程序）在管，
   改完要重启它才生效。程序每次改完都会问你要不要现在重启：

     桌面图标和任务栏会消失一两秒，然后自己回来。
     已经打开的窗口和正在做的事不受影响。

   不想现在重启也行，下次开机自然生效。
   也可以随时点右上角的「重启资源管理器」按钮手动来一次。


================================================================
 关于权限
================================================================
   程序默认用普通权限运行，这时你只能改「当前用户」的项。

   遇到来源是「系统（本机）」的项，删除时程序会告诉你改不动。
   这时点右上角的「以管理员身份重启」，Windows 会弹一次权限确认框，
   你点「是」，程序会重新打开，之后系统级的项也能改了。

   程序不会一上来就找你要管理员权限，用不上的时候不打扰你。


================================================================
 安全承诺
================================================================
   · 「扫描」这一步是纯读取，绝对不动任何东西。
   · 任何删除动作之前，一定先生成备份文件；备份没成功就不删。
   · 备份是标准的 .reg 文件，双击它也能还原，也能留着自己看。
   · 程序不联网、不收集信息、不上传任何东西。
   · 想卸载：直接删掉这个文件夹就行，它不在系统里留任何东西
     （唯一的痕迹是「我的文档\右键菜单备份」里的备份文件，可自行删除）。

   想自己验证它靠不靠谱，在命令行里跑：

       右键菜单管理器.exe --selftest 结果.txt

   程序会临时造几个假的菜单项，把「扫描 → 备份 → 停用 → 恢复 →
   删除 → 还原」整条链路真跑一遍，把结果写进「结果.txt」，
   然后把自己造的东西全部清掉。只写你自己的账户，不需要管理员权限，
   也不会碰你真实的菜单项。


================================================================
 运行环境
================================================================
   Windows 10 / 11，外加 .NET 8 桌面运行时。
   你这台电脑已经装好了，所以双击就能用。

   如果哪天换了电脑打不开，去微软官网搜「.NET 8 Desktop Runtime」
   下载安装即可（免费）。


================================================================
 文件夹里为什么只有两个文件
================================================================
   打开这个文件夹，你只会看到：

       右键菜单管理器.exe     ← 双击这个就是程序
       使用说明.txt           ← 就是你正在看的这份

   另外还有三个文件被设成了「隐藏」：

       右键菜单管理器.dll
       右键菜单管理器.deps.json
       右键菜单管理器.runtimeconfig.json

   它们是程序运行必需的东西，藏起来只是为了让你一眼看到该点哪个。
   在资源管理器里勾上「查看 → 显示 → 隐藏的项目」就能看到它们。

   搬走这个文件夹时，请整个文件夹一起搬（包括隐藏的那几个），
   单独把 exe 拷出去是打不开的。


================================================================
 一点建议
================================================================
   不确定某一项是干什么的，就先用「停用」而不是「删除」，
   用几天确认没影响，再决定要不要真删。

   来源是「系统（本机）」、状态是「系统自带」的项尽量不要动 ——
   那些是 Windows 自己的功能（打开方式、固定到快速访问、发送到…）。
   真正该清理的，通常是来源「当前用户」或者标了「已失效」的那些。
